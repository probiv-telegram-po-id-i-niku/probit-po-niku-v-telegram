## Username, ID и номер — разные вещи

Username виден в публичной ссылке, Telegram ID — постоянный числовой идентификатор, а телефон может быть скрыт настройками приватности. Поиск по одному параметру не должен автоматически подменяться утверждением о другом. Если ник сменился, старые публикации могут всё ещё содержать прежнее имя, но подтвердить связь без дополнительных открытых признаков бывает невозможно.
