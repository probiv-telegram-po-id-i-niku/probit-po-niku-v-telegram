## Что подготовить для поиска

Лучший исходный ориентир — точный username со знаком `@` или ссылка `t.me/username`. Если сохранился прежний ник, проверяйте его отдельно. Не смешивайте результаты разных написаний до того, как увидите дополнительные подтверждения.

Поиск по юзу в ТГ может показать публичные профили, упоминания и публикации, в которых встречается этот ник. Источники следует открывать вручную: поисковая выдача может содержать устаревшие страницы и однофамильцев.

## Как пробить по нику в ТГ шаг за шагом

1. Скопируйте username без лишних пробелов. Проверьте латиницу, цифры и подчёркивания: один символ меняет запрос.
2. Посмотрите доступные публичные совпадения и откройте исходные страницы, а не только краткие сниппеты.
3. Сравните дату, фотографию, описание и другие публичные ссылки. Если признаки расходятся, не объединяйте профили.
4. Запишите уровень уверенности: «совпал ник» и «подтверждён тот же аккаунт» — разные выводы.

## Username, ID и номер — разные вещи

Username виден в ссылке на профиль, Telegram ID — постоянный числовой идентификатор, а видимость телефона внутри Telegram зависит от настроек приватности. При этом связь ника с номером иногда встречается во внешних источниках. Если ник сменился, старые публикации могут содержать прежнее имя; любую найденную связь нужно перепроверять.
